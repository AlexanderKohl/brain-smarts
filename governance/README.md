# Mechanics Governance

Read `/CONTRACT.md` first.

Governance records for the mechanics layer. Active governance is the implemented content of
`/CONTRACT.md`, `/RULES.md`, the governance schemas and templates, the bootstrap files and the
preflight validator; nothing in this folder is active by being stored here (CONTRACT §13.2).

Contains canonical proposals for changes to mechanics governance, one record per
`RULE-YYYY-NNNN`. Moved here from `/projects/brain-development/proposals/` under
`RULE-2026-0046`. Proposals for the owner layer live in `/memory/governance/proposals/`.
