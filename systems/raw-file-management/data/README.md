# Data

Read `/CONTRACT.md` first.

Operational manifests or validation outputs may be stored here. Raw source files remain under `/memory/raw/`. Nothing here may identify an owner's files; owner-specific manifests belong in `/memory/systems/raw-file-management/`.

#### Folders

No immediate child folders currently exist. Future folders must contain local or generated system data, never canonical raw source files.
