# Task System Knowledge

- Tasks represent outstanding actions or directly completable outcomes.
- Projects coordinate multiple tasks over time.
- A waiting task still has one accountable owner.
- Follow-up is a system behaviour, not a separate human role.
- A due date represents a deadline.
- A next-review date represents when the system should reassess or surface a task.
