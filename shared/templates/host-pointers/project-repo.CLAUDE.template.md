# CLAUDE.md

This repository is part of a brain whose contract lives outside it (CONTRACT §16).

- **With the brain checked out:** read `CONTRACT.md` in the brain root first – on the usual
  layout the brain is a sibling folder, so `../<BRAIN_FOLDER>/CONTRACT.md` – and follow the
  bootstrap it defines. Then read this repository's `brain/README.md` and `brain/STATE.md` as the
  active node.
- **Without the brain** (for example a collaborator): read `brain/README.md` and
  `brain/RULES.md` in this repository; they are the project's own rules.
